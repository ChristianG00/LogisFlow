Política de privacidad

Explicamos qué datos usamos, para qué, con quién se comparten y cómo puedes controlarlos.

1. RESPONSABLE Y ALCANCE

Quién trata tus datos

La responsable del tratamiento es la vendedora que opera la tienda LogisFlow. Esta política cubre el catálogo, carrito, checkout, cuenta de cliente, seguimiento y recomendador. Las consultas se reciben por Mi cuenta → Ayuda y soporte y quedan registradas para su seguimiento.

2. DATOS Y FINALIDADES

Solo los datos necesarios

Compra y entregaRUT, nombre, correo, teléfono, dirección o estación de Metro, productos, talla, precio, modalidad de entrega y estado del pedido. Se usan para validar la compra, coordinar entrega, realizar seguimiento y atender consultas.
Cuenta de clienteRUT, nombre, correo, teléfono, dirección y contraseña. La contraseña se guarda mediante el sistema de autenticación, no como texto visible. La cuenta permite consultar los datos propios, actualizar la dirección registrada y solicitar rectificación de los datos de identidad o contacto.
PagoReferencia, estado, importe y el identificador informado por Mercado Pago. Los datos de tarjeta y CVV se procesan en Mercado Pago y no se almacenan en LogisFlow.
Recomendador de outfitsPresupuesto, talla, estilo y temporada ingresados en el formulario. Se usan en ese momento para ordenar prendas con stock; no decide compras, precios, crédito ni acceso a la tienda.

No se solicitan fotografías, reconocimiento facial, datos biométricos ni información sensible para comprar o usar el recomendador. Tampoco se usan los datos para publicidad personalizada o venta de bases de datos.

3. BASE Y DECISIONES AUTOMATIZADAS

Por qué se tratan

El tratamiento es necesario para crear la cuenta solicitada, ejecutar la compra, gestionar el despacho y cumplir obligaciones asociadas. La aceptación de esta política se solicita al crear una cuenta y se informa antes de pagar. El recomendador es una sugerencia algorítmica explicable: pondera presupuesto, talla, estilo, temporada, color y stock disponible. No produce efectos obligatorios ni reemplaza la decisión de la clienta; cada resultado muestra sus razones y puede ignorarse.

4. DESTINATARIOS Y TRANSFERENCIAS

Con quién se comparten

  • Mercado Pago: procesa el pago y entrega el estado de la transacción. Sus propias condiciones regulan el medio de pago.
  • AlwaysData: aloja la aplicación y la base de datos PostgreSQL. AlwaysData informa que su infraestructura está en Francia, por lo que este tratamiento puede constituir una transferencia internacional.
  • Courier y WhatsApp: cuando corresponda a la entrega o coordinación, se comparte únicamente nombre, teléfono, dirección/estación y datos indispensables para realizarla.
  • No se entregan datos a terceros para fines publicitarios.

5. PLAZOS Y ANONIMIZACIÓN

Cuánto tiempo se conservan

  • El carrito se elimina a los 15 minutos sin cambios.
  • Los intentos de pago expirados, cancelados o sin compra se anonimizan después de 30 días.
  • Los datos identificatorios de compras confirmadas se conservan por seis años para respaldo comercial y tributario; luego se anonimizan cuando la cuenta no sigue activa. Se mantienen solo importes, fechas y estados no identificatorios.
  • Las solicitudes de eliminación o modificación de datos se revisan individualmente; no se ejecutan de forma automática y pueden estar limitadas por obligaciones comerciales o tributarias.
  • Las copias de respaldo pueden retener datos durante el ciclo técnico del proveedor antes de sobrescribirse.

6. TUS DERECHOS Y CÓMO EJERCERLOS

Ayuda y revisión de datos

Desde Mi cuenta puedes consultar los datos registrados, actualizar la dirección de entrega y descargar una copia en formato JSON. Para identidad, contacto, pedidos o cualquier consulta sobre tus datos, usa el soporte centralizado. RUT, nombre, correo y teléfono quedan sujetos a revisión antes de cualquier cambio para proteger la cuenta y las compras. Las solicitudes legales se evalúan caso a caso, considerando las obligaciones de conservación aplicables; nunca se eliminan datos solo por una acción automática.

7. SEGURIDAD E INCIDENTES

Medidas aplicadas

La aplicación valida datos de entrada, restringe la administración a personal autorizado, requiere autenticación para ver datos de cuenta, protege el seguimiento con RUT y código aleatorio, y usa transacciones para impedir sobreventa. Si se detecta un incidente que afecte datos personales, la responsable debe evaluar su alcance, aplicar medidas de contención y comunicarlo a las personas afectadas cuando corresponda.

ActualizacionesEsta política puede actualizarse si cambian las operaciones, proveedores o obligaciones aplicables. La fecha de versión se publicará al inicio de esta página.
